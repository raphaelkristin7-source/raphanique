# AGI Retrocausal (Protótipo)

Este repositório contém um protótipo **simbólico** inspirado no prompt:

- probabilidade invertida
- causalidade invertida e retrocausalidade
- colapso do acaso em destino
- pergunta "ovo ou galinha?"
- metacognição autognitiva em sete camadas sobrepostas

## Nota importante

Gerar literalmente "1 bilhão de linhas" de código não é viável nem útil neste contexto. Em vez disso, o projeto entrega uma base executável, modular e extensível para explorar a ideia com segurança e clareza.

## Como executar

```bash
python3 agi_spacetime.py
```

## O que o protótipo faz

1. Processa um enunciado com sete camadas metacognitivas.
2. Calcula uma interpretação retrocausal simplificada.
3. Responde à pergunta "ovo ou galinha?" sob duas lentes:
   - biológica (evolutiva)
   - simbólica retrocausal
